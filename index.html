Pengertian Diferensiasi Numerik

Fondasi, tujuan, serta perbedaan mendasar antara diferensiasi analitis dan numerik

A Pengertian
  • Memperkirakan nilai turunan fungsi dari nilai fungsi di titik-titik diskret tertentu.
  • Sangat diperlukan saat turunan analitis sulit atau mustahil diperoleh secara eksak.
  • Metode utama ketika data yang tersedia hanya berupa tabel hasil eksperimen.
B Tujuan Utama
  • Memperkirakan laju perubahan sesaat pada sistem fisik/teknik.
  • Menghitung turunan langsung dari data diskret tanpa memerlukan persamaan analitik.
  • Membantu penyelesaian persamaan diferensial dan algoritma optimasi numerik.
C Analitis vs Numerik
  • Analitis: Hasil proses diferensiasi matematis formal menghasilkan fungsi kontinu eksak.
  • Numerik: Hasil pendekatan nilai di titik spesifik berdasarkan beda hingga nilai fungsi.

Apa Kegunaan Diferensiasi Numerik?

Memperkirakan seberapa cepat suatu nilai berubah ketika data yang tersedia hanya berupa hasil pengukuran

Aplikasi Contoh Penerapan di Dunia Nyata
  • Posisi Kendaraan: Menghitung perkiraan kecepatan ($v = \frac{ds}{dt}$) dari data sensor GPS/telemetri.
  • Kecepatan Kendaraan: Menghitung percepatan ($a = \frac{dv}{dt}$) saat kendaraan melaju.
  • Perubahan Suhu: Mengamati laju perpindahan panas ($\frac{dT}{dx}$) pada beberapa titik material.
  • Konsentrasi Zat: Memperkirakan laju reaksi kimia dari sampel waktu ke waktu.
Urgensi Kapan Metode Ini Diperlukan?
  • Ketika kita memiliki tabel atau kumpulan data pengukuran, namun tidak memiliki persamaan fungsi analitis yang bisa langsung diturunkan.
  • Fungsi matematis terlalu rumit atau berbentuk implisit non-linier.
Intinya: Kita tidak harus mengetahui persamaan fungsinya terlebih dahulu. Perubahan nilai pada data sudah cukup untuk memperkirakan nilai turunannya.
💡 Prinsip Utama: Diferensiasi numerik menjembatani data empiris diskret di lapangan dengan konsep kalkulus diferensial.

Mengenal Data dan Titik yang Digunakan

Memahami titik evaluasi $x$, langkah pengukuran $h$, dan titik tetangga di sekitarnya

Ilustrasi Contoh Data Posisi Benda

Bayangkan kita mengukur posisi benda setiap satu detik. Untuk mencari kecepatan pada detik kedua, kita amati data di sekitarnya:

Waktu $t$ (detik) Posisi $s(t)$ (meter) Peran Titik
$t = 1$ $1\text{ m}$ Titik sebelum ($x - h$)
$t = 2$ $8\text{ m}$ Titik evaluasi ($x$) ⭐
$t = 3$ $27\text{ m}$ Titik setelah ($x + h$)
Notasi Makna Variabel Kunci
  • $x$ : Titik yang ingin dianalisis. Pada contoh ini $x = 2$ detik.
  • $h$ : Jarak antar-waktu pengukuran yang konstan. Di sini $h = 1$ detik.
  • $x - h$ : Titik satu langkah sebelum titik evaluasi ($2 - 1 = 1$).
  • $x + h$ : Titik satu langkah setelah titik evaluasi ($2 + 1 = 3$).
  • $f(x)$ : Nilai data pada titik analisis, yaitu $s(2) = 8$ meter.
Kunci Perbedaan Metode: Metode diferensiasi numerik dibedakan terutama oleh data tetangga mana yang dipakai untuk estimasi.

Selisih Maju: Menggunakan Data Setelah Titik yang Diamati

Memperkirakan laju perubahan dengan membandingkan nilai pada titik sekarang dan nilai satu langkah ke depan

$$f'(x) \approx \frac{f(x+h) - f(x)}{h}$$
Bedah Rumus Komponen Persamaan
  • $f'(x)$ : Laju perubahan (kecepatan) yang ingin diestimasi di titik $x$.
  • $f(x+h)$ : Nilai data satu langkah setelah titik observasi.
  • $f(x)$ : Nilai data pada titik observasi saat ini.
  • Pembilang $[f(x+h) - f(x)]$ : Total selisih/perubahan nilai ke depan.
  • Penyebut $h$ : Menjadikan selisih per satuan waktu/jarak.
Contoh Hitungan Kasus Kecepatan di $t = 2$ ($h = 1$)

Ambil data posisi $s(2) = 8\text{ m}$ dan $s(3) = 27\text{ m}$:

$$v(2) \approx \frac{27 - 8}{1} = 19\text{ m/s}$$
Kapan cocok digunakan? Ketika data setelah titik yang dianalisis tersedia. Sangat praktis untuk titik paling awal (ujung kiri) tabel data. Orde galat: $O(h)$.

Selisih Mundur: Menggunakan Data Sebelum Titik yang Diamati

Memperkirakan laju perubahan dengan membandingkan nilai pada titik sekarang dan nilai satu langkah ke belakang

$$f'(x) \approx \frac{f(x) - f(x-h)}{h}$$
Bedah Rumus Komponen Persamaan
  • $f'(x)$ : Laju perubahan yang ingin diperkirakan pada titik $x$.
  • $f(x)$ : Nilai data pada titik observasi saat ini.
  • $f(x-h)$ : Nilai data satu langkah sebelum titik observasi.
  • Pembilang $[f(x) - f(x-h)]$ : Perubahan nilai dari titik sebelumnya ke titik sekarang.
  • Penyebut $h$ : Jarak selang antara kedua pengukuran.
Contoh Hitungan Kasus Kecepatan di $t = 2$ ($h = 1$)

Ambil data posisi $s(2) = 8\text{ m}$ dan $s(1) = 1\text{ m}$:

$$v(2) \approx \frac{8 - 1}{1} = 7\text{ m/s}$$
Kapan cocok digunakan? Ketika data sebelum titik analisis tersedia. Sangat praktis untuk titik paling akhir (ujung kanan) tabel data karena belum ada data sesudahnya. Orde galat: $O(h)$.

Selisih Tengah: Menggunakan Data Sebelum dan Sesudah

Menggunakan dua data sekaligus (kiri dan kanan) yang mengapit titik observasi secara simetris

$$f'(x) \approx \frac{f(x+h) - f(x-h)}{2h}$$
Konsep Mengapa Penyebutnya $2h$?
  • Jarak dari titik kiri ($x - h$) ke titik tengah ($x$) adalah sebesar $h$.
  • Jarak dari titik tengah ($x$) ke titik kanan ($x + h$) adalah sebesar $h$.
  • Total bentang jarak dari kiri ke kanan adalah $h + h = 2h$.
  • Keistimewaan: Nilai $f(x)$ di titik tengah sendiri tidak perlu dihitung!
Contoh Hitungan Kasus Kecepatan di $t = 2$ ($h = 1$)

Ambil data posisi $s(3) = 27\text{ m}$ dan $s(1) = 1\text{ m}$:

$$v(2) \approx \frac{27 - 1}{2(1)} = \frac{26}{2} = 13\text{ m/s}$$
Kapan cocok digunakan? Ketika data tersedia di kedua sisi titik. Menghasilkan akurasi kuadratik $O(h^2)$ yang jauh lebih teliti untuk titik dalam (interior).

Bagaimana Memilih Metode yang Tepat?

Pemilihan metode terutama bergantung pada ketersediaan data di sekitar titik yang dianalisis

Situasi Data Metode yang Digunakan Alasan & Logika Penggunaan
Data setelah titik tersedia Selisih Maju Membandingkan titik sekarang dengan titik berikutnya
Data sebelum titik tersedia Selisih Mundur Membandingkan titik sekarang dengan titik sebelumnya
Data sebelum dan sesudah tersedia Selisih Tengah ⭐ Menggunakan informasi simetris dari kedua sisi titik
Ilustrasi Praktis Penerapan pada Data Waktu $t = 1, 2, 3$
  • Pada $t = 1$ : Data sebelumnya tidak tersedia. Gunakan Selisih Maju.
  • Pada $t = 3$ : Data sesudahnya tidak tersedia. Gunakan Selisih Mundur.
  • Pada $t = 2$ : Data waktu 1 dan 3 tersedia lengkap. Gunakan Selisih Tengah.
⚠️ Hal Penting: Jangan memilih metode hanya karena rumusnya terlihat lebih mudah. Periksa dahulu ketersediaan data di sekitar titik!

Apa Perbedaan Ketelitian Ketiga Metode?

Ketiga metode menghasilkan perkiraan turunan, namun tingkat galat pemotongannya berbeda

Metode Orde Galat Pemotongan Makna Sederhana Pengaruh Jika $h$ Dibagi 2
Selisih Maju $O(h)$ Galat dominan sebanding dengan ukuran langkah Galat berkurang $\approx 2\times$
Selisih Mundur $O(h)$ Galat dominan sebanding dengan ukuran langkah Galat berkurang $\approx 2\times$
Selisih Tengah $O(h^2)$ ⭐ Galat dominan sebanding kuadrat ukuran langkah Galat berkurang $\approx 4\times$! ⭐
Praktik Apa Artinya dalam Praktik?
  • Jika $h$ diperkecil menjadi setengah, galat maju/mundur turun $\approx 50\%$.
  • Pada selisih tengah, galat turun menjadi seperempatnya ($\approx 25\%$)!
  • Berlaku selama fungsi cukup mulus dan pembulatan belum mendominasi.
Intisari Kesimpulan Praktis
  • Selisih Tengah memiliki keunggulan ketelitian teoritis tinggi, namun wajib memiliki data di kedua sisi.
  • Maju & Mundur tetap sangat berguna saat data hanya tersedia pada satu sisi batas interval.

Studi Kasus: Menghitung Kecepatan dari Data Posisi

Menghitung perkiraan kecepatan pada $t = 2$ ($h = 1$ detik) menggunakan ketiga metode

📍 Data Diketahui: $s(1) = 1\text{ m}$, $s(2) = 8\text{ m}$ (titik evaluasi), $s(3) = 27\text{ m}$ dengan selang waktu $h = 1\text{ detik}$.
1. Maju Data Waktu 2 dan 3
$$v(2) \approx \frac{s(3)-s(2)}{h}$$ $$= \frac{27-8}{1} = \mathbf{19\text{ m/s}}$$

Melihat laju interval depan $[2, 3]$.

2. Mundur Data Waktu 1 dan 2
$$v(2) \approx \frac{s(2)-s(1)}{h}$$ $$= \frac{8-1}{1} = \mathbf{7\text{ m/s}}$$

Melihat laju interval belakang $[1, 2]$.

3. Tengah Data Waktu 1 dan 3
$$v(2) \approx \frac{s(3)-s(1)}{2h}$$ $$= \frac{27-1}{2} = \mathbf{13\text{ m/s}}$$

Merata-ratakan interval $[1, 3]$ (bentang $2h$).

🔍 Observasi: Ketiga hasil berbeda ($19, 7, 13\text{ m/s}$) karena setiap metode menggunakan pasangan titik observasi yang berbeda.

Membaca dan Menafsirkan Hasil

Memahami mengapa hasil ketiga metode berbeda dan bagaimana memaknainya secara fisis

Tabel Rekap Perbandingan Hasil Kecepatan
Metode Perkiraan Kecepatan Rentang Data yang Dipakai
Selisih Maju $19\text{ m/s}$ Detik ke-2 menuju detik ke-3
Selisih Mundur $7\text{ m/s}$ Detik ke-1 menuju detik ke-2
Selisih Tengah $13\text{ m/s}$ Detik ke-1 menuju detik ke-3 (rentang 2s)
Analisis Apa yang Dapat Kita Pahami?
  • Perbedaan hasil bukan karena salah hitung.
  • Benda sedang bergerak dengan percepatan (laju terus meningkat seiring waktu).
  • Laju di interval awal ($1 \to 2$) wajar jika lebih lambat ($7\text{ m/s}$) dibanding interval berikutnya ($2 \to 3$, $19\text{ m/s}$).

Memeriksa Galat dan Menarik Kesimpulan

Memvalidasi hasil perkiraan terhadap nilai analitis eksak dari fungsi posisi $s(t) = t^3$

Eksak Nilai Analitis & Perhitungan Galat

Fungsi posisi $s(t) = t^3 \implies s'(t) = 3t^2$:

$$s'(2) = 3(2)^2 = \mathbf{12\text{ m/s}}\text{ (Nilai Eksak)}$$ $$E = |\text{hasil perkiraan} - \text{nilai eksak}|$$
Metode Perkiraan Eksak Galat Absolut
Maju $19\text{ m/s}$ $12\text{ m/s}$ $7\text{ m/s}$
Mundur $7\text{ m/s}$ $12\text{ m/s}$ $5\text{ m/s}$
Tengah $13\text{ m/s}$ $12\text{ m/s}$ $1\text{ m/s}$ ⭐
Ringkasan Pedoman Inti yang Perlu Diingat
  • Maju: Gunakan data titik saat ini dan sesudahnya ($x, x+h$).
  • Mundur: Gunakan data titik sebelumnya dan saat ini ($x-h, x$).
  • Tengah: Gunakan data sebelum dan sesudah ($x-h, x+h$).
  • Pilih Metode: Selalu sesuaikan dengan posisi titik data yang tersedia di tabel.
  • Evaluasi: Jika nilai eksak diketahui, hitung galat untuk mengukur kedekatan pendekatan.
Selisih tengah terbukti paling teliti ($E = 1\text{ m/s}$), namun metode maju & mundur tetap esensial saat data terbatas.

Konsep Dasar Turunan dari Data Tabel

Memperkirakan turunan dari tabel nilai fungsi diskrit dengan jarak langkah h yang seragam

Data Diskrit Representasi Kisi Titik Berjarak Seragam

Sering kali kita tidak memiliki rumus fungsi kontinu analitik, melainkan hanya tabel data diskrit $(x_i, f(x_i))$ yang berjarak sama $h$.

$x_0 - 2h$ $x_0 - h$ $x_0$ $x_0 + h$ $x_0 + 2h$
1,8 1,9 2,0 2,1 2,2

Contoh: Titik evaluasi utama $x_0 = 2{,}0$ dengan lebar langkah seragam $h = 0{,}1$.

Klasifikasi Dua Aspek Pembeda Metode
1. Berdasarkan Jumlah Titik Data
• Tiga Titik: Menggunakan 3 posisi data, galat $O(h^2)$, hemat data.
• Lima Titik: Menggunakan 5 posisi data, galat $O(h^4)$, presisi sangat tinggi namun butuh data lebih banyak.
2. Berdasarkan Posisi Titik ($x_0$)
• Akhir (Endpoint): Digunakan jika $x_0$ di ujung data (data hanya tersedia di satu sisi).
• Tengah (Midpoint): Digunakan jika ada data di kiri dan kanan $x_0$ secara simetris.

Rumus Tiga Titik: Akhir & Tengah

Aproksimasi turunan berorde O(h²) untuk titik batas dan interior data

Satu Sisi Tiga Titik Akhir (Endpoint)
$$f'(x_0) \approx \frac{1}{2h}\left[-3f(x_0) + 4f(x_0+h) - f(x_0+2h)\right]$$
$$\text{Galat} = \frac{h^2}{3} f^{(3)}(\xi_0), \quad \xi_0 \in (x_0, x_0+2h)$$
Bobot-3+4-1
Posisi$x_0$$x_0+h$$x_0+2h$

Faktor: $\times \frac{1}{2h}$ · Dipakai di ujung batas tabel data · Orde galat $O(h^2)$.

Simetris Tiga Titik Tengah (Midpoint)
$$f'(x_0) \approx \frac{1}{2h}\left[f(x_0+h) - f(x_0-h)\right]$$
$$\text{Galat} = -\frac{h^2}{6} f^{(3)}(\xi_1), \quad \xi_1 \in (x_0-h, x_0+h)$$
Bobot-10+1
Posisi$x_0-h$$x_0$$x_0+h$

Catatan: Tetap 3 posisi data. Koefisien $f(x_0) = 0$ sehingga nilainya tidak dihitung langsung.

Cara Menghitung: Prosedur 4 Langkah

Alur kerja sistematis menghitung turunan numerik dari tabel data diskrit

1
Tentukan $x_0$ dan $h$
Titik yang dicari turunannya adalah $x_0$. $h$ adalah jarak seragam antar-data ($h = x_{i+1} - x_i$, misal $2{,}1 - 2{,}0 = 0{,}1$).
2
Pilih Rumus yang Sesuai
Data satu sisi: rumus akhir. Data simetris: rumus tengah. Kemudian tentukan 3 titik ($O(h^2)$) atau 5 titik ($O(h^4)$).
3
Substitusi Nilai Fungsi
Ambil nilai $f(x)$ dari tabel sesuai posisi titik yang dipersyaratkan, lalu kalikan dengan bobot koefisiennya masing-masing.
4
Hitung dan Lakukan Pembagian
Jumlahkan seluruh hasil kali, lalu bagi dengan faktor pembagi: $2h$ (untuk tiga titik) atau $12h$ (untuk lima titik).
Pengingat Penting: $h$ adalah jarak antar-data, bukan nilai fungsi dan bukan hasil turunan! Rumus akhir dengan $h < 0$ digunakan dari batas kanan tabel.

Soal 1: Tiga Titik Akhir

Latihan perhitungan turunan di titik ujung data f(x) = x eˣ

$x$1,81,92,0 ($x_0$)2,12,2
$f(x)$10,88936512,70319914,77811217,14895719,855030
Deskripsi Soal Menghitung $f'(2{,}0)$

Diberikan tabel nilai $f(x) = x e^x$ di atas. Hitunglah hampiran turunan $f'(2{,}0)$ memakai rumus tiga titik akhir dengan $x_0 = 2{,}0$ dan $h = 0{,}1$, lalu tentukan galatnya!

Nilai Eksak Pembanding: $f'(x) = (1+x)e^x \implies f'(2{,}0) = 3e^2 \approx 22{,}167168$
Instruksi Langkah Pengerjaan Sistematis
  • 1. Substitusi: Ambil $f(2{,}0), f(2{,}1), f(2{,}2)$ ke rumus $[-3f_0 + 4f_1 - f_2] / 2h$.
  • 2. Kalikan: Tiap nilai $f$ dikalikan bobot: $-3$, $+4$, dan $-1$.
  • 3. Bagi: Jumlahkan hasil kali, lalu bagi dengan $2h = 0{,}2$.
  • 4. Galat: Tentukan $\text{galat} = \text{eksak} - \text{hampiran}$.

Metode Ekstrapolasi Richardson

Menggabungkan dua pendekatan dengan ukuran langkah berbeda untuk membuang suku galat utama, sehingga hasilnya lebih teliti.

1
Hitung pendekatan turunan dengan langkah $h \rightarrow D(h)$
→
2
Hitung pendekatan dengan langkah $2h \rightarrow D(2h)$
→
3
Gabungkan keduanya untuk mengurangi galat utama
Rumus Umum Kombinasi Linier Dua Langkah
$$f'_0 = D(h) + \frac{D(h) - D(2h)}{2^n - 1}$$
  • $f'_0$ : nilai turunan di $x_0$ setelah ekstrapolasi
  • $D(h)$ : hasil pendekatan turunan dengan langkah $h$ yang lebih kecil
  • $D(2h)$ : hasil pendekatan turunan dengan langkah dua kali lebih besar
  • $n$ : orde galat awal, yaitu $O(h^n)$

Kedua hasil digabung untuk menghilangkan suku galat utama.

Contoh: Selisih Tengah Kasus $n = 2$
$$f'_0 = \frac{4D(h) - D(2h)}{3}$$
Peningkatan Akurasi: Orde galat naik: $O(h^2) \rightarrow O(h^4)$
Kaitan notasi slide berikut: $D(h) = N_1(h/2)$, $D(2h) = N_1(h)$.
Untuk $n = 1$ (selisih maju): $2D(h) - D(2h)$.

Kesimpulan

Rangkuman poin-poin utama materi Diferensiasi Numerik

Poin Utama Esensi Pembahasan
  • Diferensiasi numerik memperkirakan turunan dari nilai-nilai fungsi diskret.
  • Pendekatan deret (Polinomial Lagrange dan Deret Taylor) menjadi fondasi matematis utama seluruh rumus.
  • Selisih maju dan mundur menghasilkan galat pemotongan O(h)O(h)O(h).
  • Selisih tengah dan tiga titik ujung mencapai akurasi O(h2)O(h^2)O(h2).
  • Metode lima titik (tengah dan ujung) mencapai ketelitian tinggi O(h4)O(h^4)O(h4).
  • Ekstrapolasi Richardson terbukti sangat efektif mendongkrak ketelitian dengan mengeliminasi suku galat dominan.
Prinsip Bijak Pemilihan Ukuran Langkah hhh
“Ketelitian diferensiasi numerik tidak hanya ditentukan oleh rumus yang digunakan, tetapi juga oleh ukuran langkah hhh, data yang tersedia, dan sifat fungsi.”

Pemilihan hhh harus mempertimbangkan trade-off antara galat pemotongan dan akumulasi galat pembulatan komputer.
